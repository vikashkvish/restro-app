# Restro App

Restaurant ordering system supporting dine-in (QR code), takeaway and delivery.

## Tech Stack
- Frontend: Next.js (JavaScript), Tailwind CSS
- Backend: Node.js, Express, Prisma, PostgreSQL, Socket.IO

## Structure
- `apps/web`: customer, admin and kitchen UI
- `apps/api`: REST API and real-time server

## Getting Started
Setup instructions will be added as we build each part.

## Branching and Commits
- `main`: stable, production-ready code only
- `develop`: integration branch
- `feature/<name>`: one branch per feature
- Commit style: `feat: add menu API`, `fix: cart total bug`, `chore: update deps`
